# Nexus Performance — projeto novo do zero

Reconstrução mobile-first baseada na referência visual enviada.

Módulos:
- Dashboard
- Glicemia ao longo do dia
- Dieta com 6 refeições + ceia
- 5 substituições por alimento
- Registro de insulina aplicada por refeição
- Treinos A–E com imagem de referência
- Séries, repetições, carga e RPE
- Histórico local
- PWA para iPhone

Publicação:
- Pode ser publicado no GitHub Pages como site estático.
- O mesmo endereço pode ser adicionado à Tela de Início do iPhone.

Nota:
- O app não calcula nem recomenda doses de insulina; o campo é para registrar a dose aplicada.
